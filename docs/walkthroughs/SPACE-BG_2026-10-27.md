## 1. Executive Summary

The flat `night` page background has been replaced across the entire portfolio with a persistent, cinematic **space background**:
1. **Base & Multi-Point Nebula:** Fixed `-z-50` background rendering a deep-space base (`--color-space` `#030010`) combined with a 4-point CSS radial gradient nebula (orange solar corona on the left edge, teal cloud in centre-right, deep cosmic blue top-right, galactic violet lower-left). The nebula smoothly drifts upward with scroll progress via CSS `animation-timeline: scroll(root block)` without JS overhead.
2. **HTML5 Canvas 2D Starfield (`Starfield.tsx`):** Client leaf component rendering 900–2000 delicate, crisp stars across 3 small depth layers (radii 0.35–1.15 px; oversized discs and glow halos removed) with independent sine-wave twinkling. Stars drift automatically from bottom to top at a serene, slow pace (~4.5–7 px/sec; speed reduced by 70%), with star displacement decoupled from page scroll.
3. **Transparent Global Chrome:**
   - **Header:** Completely transparent at top of page; scrolled state uses `bg-space/30 backdrop-blur-md border-b border-line` allowing stars to shine through while keeping text legible. Fullscreen mobile menu uses `bg-space/85 backdrop-blur-xl`.
   - **Footer:** Removed `bg-night` fill; root is 100% transparent with hairline borders (`border-line`) and signature oversized wordmark floating directly over deep space.
   - **Sticky Bars:** Services sticky sub-nav and Experience mobile rail use `bg-space/50 backdrop-blur-md border-line`. Scroller edge gradients (`from-night`) replaced with CSS `mask-image` fades.
4. **Hero Poster Seamless Blend:** Verified hero poster image blend has zero visible bounding boxes or hard edges at 1440px and 375px.

## 3. Tokens & Styling Specification

Added to `src/app/globals.css` `@theme`:
```css
  /* space background (see docs/context/03 §2) */
  --color-space: #030010;
  --color-nebula-solar: rgb(255 68 0 / 0.28);
  --color-nebula-cyan: rgb(0 180 160 / 0.2);
  --color-nebula-blue: rgb(0 102 255 / 0.22);
  --color-nebula-violet: rgb(130 30 180 / 0.15);
  --color-star: #ffffff;
  --color-star-glow: #b4dcff;
```

Base Layer (`@layer base`):
```css
html {
  color-scheme: dark;
  background-color: var(--color-space);
}
body {
  background: transparent; /* must be transparent so fixed -z-50 background paints through */
  color: var(--color-fg);
  font-family: var(--font-body);
  font-size: 1.125rem;
  line-height: 1.7;
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
}
```

Nebula & Scroll-Driven Drift (`@layer components`):
```css
.space-nebula {
  background-color: var(--color-space);
  background-image:
    radial-gradient(circle at 0% 50%, var(--color-nebula-solar) 0%, transparent 45%),
    radial-gradient(circle at 60% 55%, var(--color-nebula-cyan) 0%, transparent 55%),
    radial-gradient(circle at 100% 20%, var(--color-nebula-blue) 0%, transparent 50%),
    radial-gradient(circle at 30% 85%, var(--color-nebula-violet) 0%, transparent 45%);
}

@keyframes nebula-drift {
  from { transform: translate3d(0, 0, 0); }
  to   { transform: translate3d(0, -6%, 0); }
}

@media (prefers-reduced-motion: no-preference) {
  @supports (animation-timeline: scroll()) {
    .nebula-drift {
      animation: nebula-drift linear both;
      animation-timeline: scroll(root block);
    }
  }
}
```

## 6. Contrast Audit Results

- **Base Deep Space (`#030010`):** Luminance `0.0007`
- **Orange Corona Peak (`rgb(255 68 0 / 0.28)` on base):** Luminance `0.0195`
  - `text-fg` (white): **15.11:1** (WCAG AAA)
  - `text-fg-muted`: **7.53:1** (WCAG AAA)
  - `text-fg-subtle`: **5.41:1** (Exceeds WCAG AA 4.5:1 threshold)
- **Teal Gas Cloud Peak (`rgb(0 180 160 / 0.20)` on base):** Luminance `0.0146`
  - `text-fg` (white): **16.24:1** (WCAG AAA)
  - `text-fg-muted`: **8.10:1** (WCAG AAA)
